# FIN-GUARD checkpoint

Download [fin_guard.joblib](models/fin_guard.joblib) for the FIN-GUARD course project. The checkpoint contains the fitted scaler, DBSCAN core-point index, K-Means baseline, PCA projection and alert thresholds selected before holdout scoring.

Use scikit-learn 1.9.1 and the dependencies from the submission ZIP. Place the file in the project's models directory and run `python train.py --benchmark` from the extracted project folder.
